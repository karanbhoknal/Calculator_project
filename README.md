# 🧮 Advanced Calculator (Tkinter + Python)

This is a **GUI-based Advanced Calculator** built using **Python’s Tkinter library**.  
It supports basic arithmetic operations as well as **scientific functions** such as `sqrt`, `sin`, `cos`, `tan`, `log`, `exp`, `pow`, `mod`, and `abs`.

---

##  Features
- ✅ Dark-themed user interface  
- ✅ Basic operations: Addition, Subtraction, Multiplication, Division  
- ✅ Decimal support  
- ✅ Clear (`C`) button to reset expression  
- ✅ Scientific functions:
  - Square root (`sqrt`)
  - Trigonometric functions (`sin`, `cos`, `tan`)
  - Logarithm (`log`)
  - Exponential (`exp`)
  - Power (`pow`)
  - Modulus (`mod`)
  - Absolute value (`abs`)
- ✅ Handles invalid expressions gracefully (shows `Error`)

## ▶️ How to Run
1. Clone this repository or download the `calculator.py` file.
2. Open a terminal and run:
   ```bash
   python calculator.py
   
3. The calculator window will open

4. 🎮 Usage

Click on the buttons to build your mathematical expression

Use = to evaluate the expression

Use C to clear the input field

For functions like sqrt, sin, log, etc., the program automatically adds an opening parenthesis (.
👉 You need to close it manually with ) before evaluation.
